# Genesis live stage

Created: 2026-09-11. Requested by Lucas. Status: implementation.

## Settled brief

Make Genesis the working window for requests such as: run X tasks from Y task
set, audit previous architectures and AutomationBench history, design a product
graph candidate, and compare completion and speed against native harnesses.
Lucas requests subagents, expressive ASCII motion, streamed reusable cards,
and visible configuration at important moments. Delivery and targeted checks
take priority over an expanded testing framework.

## User stories and acceptance

1. A reader watches actual research and tools in the Genesis conversation and
   persistent window. Thinking, research, architecture, configuration, execution,
   results and blocked work have distinct illustrations and text. No fabricated
   percentage or benchmark verdict is presented.
2. Genesis calls a typed presentation tool to publish or replace a card. The
   receipt is retained in the existing turn stream and restores after reload.
   Strings are escaped; navigation is restricted to Studio routes.
3. Genesis shows a feature while existing tools configure it. Following can be
   stopped and never steals keyboard focus or discards an unsaved edit.
4. A benchmark architecture request starts from recorded history, names a
   falsifiable candidate and preserves comparable requests, immutable upstream
   tasks, spend gates and separate native-harness baselines.

## Constraints and edge cases

Keep ongoing voice, conversation and mission behavior. Respect reduced motion,
pause controls and hidden tabs. Repeated receipts update stable cards. Completed
tool calls are observable actions, not evidence a benchmark task passed. Missing
metrics remain unknown. No benchmark launch is implied by this example query.

## Success criteria

Offline browser evidence at desktop and phone widths demonstrates the stage,
updated cards and navigation without overflow or console errors. Focused existing
Genesis checks remain passing. Record exact limitations of live acceptance.
