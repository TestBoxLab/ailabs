blocks are correct. This note records them so the next person does not rediscover them.


## What this does not block

The measurement side of FR-027 landed without it. `measures.per_execution` reads a
run-only round as the engine alone — cost and wall clock per execution, per task — and
is tested against stored rows shaped as the orchestrator writes them
(`tests/test_studio_measures.py`). The measure is ready for the day a run exists; what
is missing is the run, not the reader.

One point worth keeping when that day comes. In run-only mode `configure_usd` is
**not applicable**, never zero. The recipe was authored once, by this command, outside
the round. A zero would say the engine is free to set up, which is the opposite of what
the break-even curve exists to measure.

## Money, for whoever unblocks this

Stated here because it is the number that decides whether the round is affordable, and
it is not obvious from the plan.

An attempt whose cost cannot be read **holds its whole ceiling against the week**
rather than settling — `wb_orchestrator/budget.py` counts a reservation with a NULL
actual at its maximum. The Monarch default ceiling is US$ 25.00 an attempt
(`wb_arms/monarch.py:52`). Ten unreadable attempts therefore hold the entire US$ 300
week even if they cost cents. Before this round runs, confirm Langfuse is answering:
a silent telemetry outage does not fail the round, it exhausts the budget.

The hold no longer lasts for ever. It still survives the Monday rollover — a week
boundary is not evidence that a charge did not happen — but a named person can now
release one:

```
wb budget release <reservation_id> --because "Langfuse outage; no cost was ever reported." --by human:lucas
```

`wb budget status` lists what is blocking as `unknown_hold_ids` beside `held_usd`, so
a blocked week reads as unknowns rather than as spending. A released hold stays
unsettled and unknown on the record, `wb budget reconcile` still counts it against the
provider's own export, it can never be dispatched again, and a total that arrives late
still settles and charges its weeks.
