## Operational checklist before any round

1. `ngrok http --domain=imputable-tracklessly-kellan.ngrok-free.dev 127.0.0.1:9105`
   must be running on this machine (`curl http://127.0.0.1:4040/api/tunnels`).
   `wb doctor` does not check it yet (deferred.md).
2. Monarch up: `bash ../monarch/local-docs/setup/scripts/railway-ops.sh status`
   (`unlock` takes 8 to 12 min; `lock` after the round).
3. Seeds deployed and in sync: `bench-seeds.sh status`; the root `ok.txt`
   names the seeds version and sha.
4. `wb doctor --arms monarch`; hashes in `docs/rounds/*.md` match
   `config.resolve(...)`.
5. Start a round with `echo y | uv run wb run --product simulated-apps --plan <plan>`
   detached (`nohup ... &`), never inside a 10-minute tool call; `out/chain_rounds.sh`
   runs several rounds with the "at least one Monarch pass" gate.
6. Post to `#ai-labs` (C0BU26293CM) with the plugin Slack MCP, the approved
   message in this conversation's history (Easy/Average posts as examples).
